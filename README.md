# Payout Street

From [OnTheTape](https://onthetape.io). A receiving yard for observed prop-firm payouts.

Crates = the tape. Plates = the only thing for sale ($9 / $29 / $79 a month). A plate cannot add a crate.

Live: https://diatle-glitch.github.io/payoutstreet/

This is not Night Circuit (`diatle-glitch/payout-street`). Do not replace that race with this yard.
